### Security Features

#### Strong Password Hashing
- **Algorithm**: bcrypt with 12 rounds (2^12 = 4,096 iterations)
- **Salt**: Unique per password (auto-generated by bcrypt)
- **Resistance**: Protects against rainbow table and brute force attacks
- **Performance**: ~200-300ms per hash (intentionally slow)

#### Backward Compatibility
- Plain text passwords continue to work
- Automatic detection of password format
- Zero-downtime migration path
- No breaking changes to existing deployments

#### Constant-Time Comparison
- Username comparison uses SHA-256 + timingSafeEqual()
- Bcrypt.compare() is inherently constant-time
- Plain text fallback uses constant-time safeCompare()
- Prevents timing attacks on both username and password

#### Layered Security
1. **Rate Limiting**: 5 login attempts per 15 minutes (already implemented)
2. **Session Management**: Redis-backed with configurable TTL
3. **Password Hashing**: Bcrypt with 12 rounds (this implementation)
4. **Constant-Time Comparison**: Prevents timing attacks
5. **Bearer Token Auth**: For API requests after login
